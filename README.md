# Dynamic MCQ Quiz & Evaluation System

## Project Overview
This project is a console-based MCQ Quiz Application developed in C++ using the Data Structure concept of Singly Linked Lists. The application dynamically stores quiz questions and student responses using linked lists instead of static arrays.

## Data Structures Used
- Singly Linked List
- Dynamic Memory Allocation
- Structures (struct)
- Pointers

## Linked Lists Used

### 1. Question Bank Linked List
Stores:
- Question Number
- Question
- Four Options
- Correct Answer

### 2. Student Response Linked List
Stores:
- Question Number
- Correct Answer
- User's Answer
- Points Earned

## Features
- Add multiple-choice questions dynamically.
- Store questions using a linked list.
- Attempt the quiz.
- Compare user answers with correct answers.
- Generate a final performance report.
- Display total score.

## Technologies Used
- C++
- Visual Studio Code

## Concepts Used
- Structures
- Pointers
- Linked Lists
- Dynamic Memory Allocation
- Functions
- Traversal
- Insertion at End

## Project Flow
1. Create the Question Bank Linked List.
2. Insert quiz questions.
3. Traverse the question list.
4. Accept user responses.
5. Store responses in another linked list.
6. Evaluate answers.
7. Display the final report and score.
